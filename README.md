# HR Compensation Analysis (R)

## 💼 Business Problem

HR teams need to understand employee salary distribution across departments to support compensation planning and workforce analysis. Manual salary reviews make it difficult to identify salary trends and compare departments effectively.

---

## 📌 Project Overview

This project analyzes employee salary data using **R**. The analysis focuses on salary distribution, department-wise comparison, and basic descriptive statistics.

---

## 🎯 Business Objectives

- Analyze employee salary distribution.
- Compare salaries across departments.
- Calculate average, minimum, and maximum salaries.
- Support HR reporting with simple visualizations.

---

## 📂 Dataset Information

The dataset contains employee records including:

- Employee ID
- Employee Name
- Department
- Salary

---

## 🛠️ Tools & Technologies

- R
- RStudio

---

## 📊 Analysis Performed

- Average Salary
- Minimum Salary
- Maximum Salary
- Department-wise Salary Analysis
- Bar Chart Visualization

---

## 💡 Key Insights

- Salary distribution varies across departments.
- Department-level analysis helps identify compensation patterns.
- Summary statistics provide a quick overview of employee salaries.
